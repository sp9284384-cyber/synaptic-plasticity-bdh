The Fading Wire

Claim: Temporarily strengthening the connections between recently co-active neurons lets a network hold information without a dedicated memory slot for it — but that memory decays over time, and can be overwritten (forgotten) when unrelated activity competes for the same wiring. Watch this happen below, then read how it maps onto BDH's synaptic memory.

"Theoretical" = what synapse (0,1) would be if it only ever grew and never decayed (pure textbook Hebb rule: w += η·x·y). "Actual" = the same synapse in this simulation, which also decays every tick. The gap between them is the whole lesson: short-term memory in BDH is not a stored value, it's a weight that must be actively maintained or it fades.

2 — Guided walkthrough

1

Click "Fire pattern A" — neurons 0, 1, 2 activate together repeatedly. Watch the synapses between them brighten: this is the Hebbian update w = decay·w + η·x·y running live, every tick.

2

Click "Test recall of A" at any point — this pings the network and shows how strongly 0–1–2 "remembers" being co-active, with no further learning happening.

3

Click "Trigger interference" — a different, overlapping pattern (2, 3, 4) fires instead. Neuron 2 is shared with pattern A, so its wiring budget gets pulled toward the new pattern while A's un-reinforced synapses keep decaying, uninterrupted.

4

Test recall of A again — if enough time/interference has passed, the earlier association is measurably weaker or gone: this is forgetting through interference, not deletion — nobody erased it, it just wasn't maintained.

5

Try the sliders — push decay near 0.999 and the memory becomes almost permanent (closer to slow, parameter-like weights); drop it toward 0.80 and even actively-reinforced patterns barely hold — this is the stability–plasticity trade-off in miniature.

Where this lives in BDH

Primary source Pathway's Dragon Hatchling (BDH) paper defines exactly this update as its core working-memory mechanism. The paper states it directly:

Y(i), X(j) → σ(i,j)
"neurons that fire together, wire together" — interpreted as in-context fast-weight updates.

Here σ(i,j) is BDH's synaptic strength (our w), and Y(i)/X(j) are pre/post-synaptic activity (our y/x). The paper's own physical analogy — "elastic connectors... tension relaxes over time unless reinforced" — is precisely the decay term this demo makes visible.

Documented result In trained BDH-GPU models, researchers found individual synapses that reliably spike for specific concepts (a "currency synapse," a "country synapse") — sparse (~5% of neurons active per token) and consistent across languages. This is reported, primary-source evidence, not a live run reproduced here.

Read more: The Dragon Hatchling paper (arXiv:2509.26507) · Pathway's BDH explainer, Ch.2

Limitation / honesty check

This toy network has 5 neurons and a symmetric (undirected) weight, built purely for visibility. Real BDH's σ is directional, lives in a much higher-dimensional sparse space (never fully materialized — BDH-GPU approximates it via a low-rank state ρ), and its "interference" emerges from shared, capacity-limited neuron activity rather than the simplified decay-dominated forgetting shown here. This is an independent illustrative simplification of the same update rule — not a reproduction of BDH itself.
